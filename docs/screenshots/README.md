## 🛠 추천 캡처 도구

- **Windows**: [ShareX](https://getsharex.com) (스크린샷 + GIF 모두 무료)
- **Windows GIF only**: [Screen2Gif](https://www.screentogif.com) (가벼움, 한국어 지원)
- **macOS**: 기본 캡처 (Cmd+Shift+5) + [Gifski](https://gif.ski/) 로 변환
- **압축**: [TinyPNG](https://tinypng.com) (PNG 70% 축소), [ezgif.com](https://ezgif.com) (GIF 최적화)

> 💡 **Tip**: GitHub 가 README 에 표시하는 이미지는 5MB 이내 권장. GIF 가 클 경우 fps 를 낮추거나(15→10) 길이를 줄이세요.
